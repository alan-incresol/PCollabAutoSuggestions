# Autosuggest API documentation

The canonical **developer documentation** for the Atlas Search autosuggest endpoint (`POST /api/autosuggestions/suggest`) is maintained in the **DataLine** project:

`dataline/backend/docs/AUTOSUGGEST_API.md`

This PCollab Search Suggestions repo holds the standalone demo backend and `search-indexes/*.json` reference mappings. Production integrations should follow the DataLine document and `dataline/api/autosuggestions/search_registry.py`.
